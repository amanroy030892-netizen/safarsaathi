# SafarSaathi — Assam Real-Time E-Rickshaw & Carpool App 🛺🚗

SafarSaathi is a real-time peer-to-peer E-Rickshaw radar and intercity carpooling platform built for Assam and North-East India.

## Key Features
- **3D Frosted Glassmorphism UI**: Clean English interface with zero-scroll screen fit across mobile devices.
- **Interactive Selfie Face Cropper & Daily Driver Verification**: Users can drag/zoom their photo Up/Down so only their face fits inside the circular Profile Photo, and drivers capture a live Daily Selfie before posting an E-Rickshaw or Car Ride.
- **Pinpoint OSRM Street-Locked GPS**: Real-time road-snapped tracking for 3-Wheeler E-Rickshaws and 4-Wheeler Cars across Assam.
- **Encrypted App-to-App WebRTC Voice Calling**: Direct in-app voice communication between verified passengers and active drivers with hands-free speaker auto-connect.
- **Verified Community Safety**: Mandatory login gate, 1-Mobile-1-Aadhaar identity verification, referral discount wallet, and 24x7 complaint support desk.
- **Privacy & Data Safety**: Full compliance with Google Play User Data and Account Deletion policies (`privacy.html#delete-account`).
